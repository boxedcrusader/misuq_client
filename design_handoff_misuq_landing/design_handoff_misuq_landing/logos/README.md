# Misuq Logo Assets

The final mark is the **rising-baseline** logo: three circles that grow in size and rise along the baseline — a story gaining reach as it graduates from a small preview audience to a wider one.

## Files
- `misuq-mark.svg` — the standalone mark (light backgrounds)
- `misuq-mark-dark.svg` — the mark tuned for dark backgrounds
- `misuq-app-icon.svg` — the mark on a rounded `#5B4FE9` tile (launcher / favicon)
- `misuq-lockup.svg` — mark + "Misuq" wordmark, horizontal (light)
- `misuq-lockup-dark.svg` — same, for dark backgrounds

## Notes
- Dot palette (light): `#C7C2E8` · `#8E84EE` · `#5B4FE9`
- Dot palette (dark): `#6E64C8` · `#8E84EE` · `#8579FF`
- The wordmark is **Space Grotesk 600**, tracking `-0.03em`. The lockup SVGs reference the font by name; install/import Space Grotesk to render the wordmark exactly, or convert the text to outlines in a vector editor for a portable file.
- The mark reads clearly down to 16px — the size gap between dots carries it when tint contrast fades.
